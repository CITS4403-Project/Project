\section{Experimental design}
\label{sec:experiments}

Five runner families produce the evidence, each from one command in the
repository root. They load the frozen graph and write their tables and figures
under \texttt{results/} and \texttt{figures/}; Table~\ref{tab:design} lists the
scenarios, runner defaults and outcome measures.

All runs use master seed 0 and derived child seeds: paired conditions share
draws and repeated draws stay separate observations. Each runner writes one
row per replicate through \texttt{experiments.save\_table}, with a
\texttt{.meta.json} sidecar holding the seed, parameters, package versions and
SHA-256 input hashes; \texttt{--quick} variants are smoke tests in separate
directories.

The runners call the
packaged engines and store raw per-seed rows under \texttt{results/<family>/};
the P1.2 helpers summarise them; \texttt{make figures} checks the tables
against their sidecars, then writes the report figures and the macros in
\texttt{sections/00-results-values.tex}; and Section~\ref{sec:results} cites
those frozen files. Notebooks 01 to 04 re-execute the same calls interactively.
\texttt{make check} runs the test suite and \texttt{make reproduce} chains
\texttt{data}, \texttt{check}, \texttt{figures} and \texttt{notebooks}; each
family regenerates with its command in Table~\ref{tab:design}.
\path{run_uncertainty.py} verifies the committed P2.2 manifest first, so P2.2
is regenerated before it if its inputs change.
